# Backipedia

**Backipedia. Manuscripts don't burn.**

A browser extension that lets you view and compare historical versions of Wikipedia articles — preserving the record against revision, erasure, or ideological rewriting.

## What is Backipedia?

Backipedia is an open-source browser extension that gives users direct, automatic access to earlier versions of Wikipedia pages. It prioritizes transparency by making changes visible and debatable rather than hidden.

Instead of relying on the current live version of an article, Backipedia lets you:

- View pre-2023 (or any chosen historical) versions of pages
- See clear diffs and semantic change analysis
- Fall back to web archives (primarily Wayback Machine) for deleted articles
- Maintain user-controlled views that can incorporate legitimate updates while preserving core historical context

The project follows a simple philosophy: **don't write petitions, write code**.

## Why Backipedia?

Wikipedia is one of the most important sources of knowledge on the internet and a major training source for AI systems. When large-scale, coordinated changes occur to articles — especially on politically or culturally sensitive topics — the public record can shift dramatically without most readers noticing.

Backipedia seeks to:

- Preserve access to earlier versions of articles
- Make significant edits visible and analyzable
- Provide users with tools to understand *what* changed and *when*
- Offer a decentralized, client-side layer of protection for the historical record

"Manuscripts don't burn" — true ideas and records have a way of surviving when people build the tools to protect them.

## Key Features (Planned)

- **Historical View**: One-click access to pre-selected or custom historical versions using Wikipedia's own revision history
- **Change Analysis**: Transparent highlighting of structural, thematic, and semantic shifts between versions
- **Deleted Pages Support**: Automatic fallback to Wayback Machine (and other archives) when articles have been removed
- **Open Logic**: All rules for change detection and analysis are public, auditable, and configurable
- **User Agency**: Options to blend historical versions with verified factual updates
- **Privacy-focused**: Runs client-side with minimal external dependencies

## How It Works

1. On any Wikipedia page, Backipedia offers a "Historical View" option.
2. It first attempts to retrieve the desired version directly from Wikipedia's revision API.
3. For deleted pages or missing snapshots, it falls back to the Internet Archive's Wayback Machine.
4. Change analysis tools surface meaningful differences using open, documented logic.

- Transparency over trust
